# ADR-0003: PostgreSQL для учётки, доступа и доски владельца

## Статус

Принято (2026-11-25).

## Контекст

Фича `005-postgres-profile-auth` вводит учётную запись с ником, JWT-доступ, доску владельца и журналы в одном хранилище PostgreSQL. Ранее JSON-файл `data/board.json` обслуживал локальный CLI и переходный `GET/PUT /api/board` (см. ADR-0001). SQLite и маршрут `/profiles` остаются отдельной моделью профиля.

## Решение

- Учётка, строки доступа, доска, карточки, метки, журнал владельца и журнал оператора хранятся в PostgreSQL 17.
- Приложение подключается ролью `kanban_app`; миграции применяет `kanban_migrator`.
- `data/board.json` остаётся хранилищем локального CLI и переходного `/api/board`, не доски владельца по `/v1`.

## Последствия

- Поставка включает отдельный контейнер `postgres` и обновлённый `docker-compose.yml`.
- ADR-0001 не переписывается: JSON по-прежнему описывает локальную доску CLI.
